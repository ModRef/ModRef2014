# ModRef 2014

Archived website of the ModRef 2014 workshop, restored so it keeps serving at
<https://2014.modref.org>.

* **Original URL:** <http://cp2014.a4cp.org/workshops/modref14>
* **Source:** Internet Archive capture `20141015110617`

The pages are the original HTML. Only links were rewritten: papers and slides now
point at <https://archive.modref.org>, and links into the surrounding conference
site point at their Internet Archive captures. `.nojekyll` keeps GitHub Pages from
reprocessing the historic markup.

Part of the ModRef series archive — <https://archive.modref.org>.
